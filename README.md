# دفتري — Daftari

[![Build and test](https://github.com/islambenmebarekdz-collab/Daftari/actions/workflows/ci.yml/badge.svg)](https://github.com/islambenmebarekdz-collab/Daftari/actions/workflows/ci.yml)

**تطبيق ملاحظات عربي مصمم من الأساس لقارئ الشاشة NVDA** — بمفهوم Obsidian: ملاحظاتك ملفات Markdown عادية في مجلد تملكه أنت، مترابطة بروابط ويكي ووسوم وبحث شامل.

*An Arabic-first, NVDA-screen-reader-native note-taking app for Windows. Obsidian-style: your notes are plain Markdown files you own, connected with wiki links, tags, and full-text search. English UI available in Settings.*

## لماذا دفتري؟

معظم تطبيقات الملاحظات تُبنى للعين أولاً ثم "تُرقّع" للإتاحة. دفتري بُني بالعكس: كل ميزة صُممت لتعمل بالكامل من لوحة المفاتيح ويقرأها NVDA بوضوح، من التنقل بين الفقرات إلى تحرير الجداول.

## أبرز الميزات

- **ملفات Markdown عادية** في مجلد «القبو» — متوافقة مع Obsidian وأي محرر آخر، ولا احتكار لبياناتك.
- **روابط ويكي** `[[اسم الملاحظة]]`: اكتب `[[` فتُفتح قائمة الملاحظات لإكمال الرابط، واتباع بـ Ctrl+Enter، وروابط واردة Ctrl+B، وصادرة Ctrl+L.
- **حماية بياناتك**: كشف التعديلات الخارجية قبل الكتابة فوقها (مع خيارات لا يضيع معها نص)، و**قفل اختياري للملاحظات الحساسة** بكلمة مرور (AES-256-GCM مع PBKDF2 بـ 600,000 دورة).
- **بحث واستبدال** داخل الملاحظة (Ctrl+H).
- **إشارات غير مرتبطة**: يكشف الملاحظات التي تذكر اسم ملاحظتك كنص عادٍ، وF2 يحوّلها إلى رابط بضغطة واحدة.
- **بحث مرجّح ومتعدد الكلمات** (Ctrl+Shift+F): يجد الملاحظات الحاوية لكل الكلمات ولو في أسطر متفرقة، مرتّبةً بالعنوان ثم العبارة الكاملة ثم الوسوم ثم عدد التطابقات.
- **محرر جداول شبكي** (Ctrl+Shift+G): أنشئ وحرر جداول Markdown في شبكة يقرؤها NVDA صفاً وعموداً كما في Excel — دون كتابة أي رمز.
- **معاينة HTML** (Ctrl+Shift+H): تفتح الملاحظة في المتصفح بعناوين وقوائم وجداول دلالية، وكل قسم قابل للطي والتوسيع.
- **تنقل صوتي ذكي**: بين الفقرات Ctrl+الأسهم (وصفوف الجداول تُقرأ خلايا نظيفة)، بين العناوين Alt+الأسهم، و«أين أنا؟» Ctrl+I يعلن موضعك كاملاً.
- **المهام**: F4 يحوّل السطر إلى مهمة أو يبدّل إنجازها، وCtrl+M يجمع **كل مهام القبو** في قائمة واحدة تفتح مصدر كل مهمة أو تعلّمها منجزة من مكانها.
- **القوالب**: F7 ينشئ ملاحظة من قالب بمتغيّرات ({{العنوان}}، {{التاريخ}}، {{المؤشر}}…)، وقالب باسم «يومية» يُستعمل تلقائياً مع ملاحظة اليوم.
- **تنظيم كامل داخل التطبيق**: نقل بشجرة مجلدات (Ctrl+Shift+M)، قائمة إجراءات على كل عنصر، مدير محذوفات، وترتيب مرن للشجرة.
- **مزامنة اسم الملف مع العنوان**: تعديل السطر الأول يعيد تسمية الملف ويحدّث كل الروابط المشيرة إليه.
- **وسوم** Ctrl+T، **يوميات** Ctrl+D، **فتح سريع** Ctrl+P، **تنقل فوري بين ملاحظتين** Ctrl+Tab.
- **تراجع وإعادة متعددا المستويات**، حفظ تلقائي، والحذف إلى مجلد محذوفات قابل للاسترجاع.
- **نسخ احتياطي** يدوي (Ctrl+Shift+B) وتلقائي عند الإغلاق مع تدوير النسخ، **واستعادة من داخل التطبيق** إلى مجلد جديد بلا مساس بملاحظاتك — ضعه داخل Google Drive أو OneDrive لمزامنة سحابية تلقائية.
- **استئناف العمل**: يفتح آخر ملاحظة عملت عليها **عند موضع المؤشر الذي تركته**، مع قوائم «المعدّلة حديثاً» و«المثبّتة».
- **تصدير إلى HTML**: ملاحظة واحدة أو القبو كله مع صفحة فهرس — وWord يفتح HTML مباشرة.
- **واجهة ثنائية اللغة** (عربي/إنجليزي) وتنسيقات تاريخ متعددة منها أسماء الأشهر الجزائرية (جانفي، فيفري…).

اضغط **F1** داخل التطبيق لقائمة الاختصارات الكاملة.

## التحميل والتشغيل

لا يحتاج التطبيق تثبيتاً ولا أي متطلبات مسبقة:

1. حمّل أحدث إصدار من صفحة [Releases](../../releases).
2. فك الضغط وشغّل `Daftari.exe`.
3. عند أول تشغيل يُنشأ مجلد ملاحظاتك في `المستندات\دفتري`.

المتطلبات: ويندوز 10 أو 11 (64 بت).

## البناء من المصدر

يتطلب .NET 8 SDK على ويندوز.

```
dotnet build Daftari.sln -c Release
dotnet test Daftari.sln -c Release
```

### النشر

سكربت واحد يبني ويشغّل كل الاختبارات — **ويتوقف إن فشل أي اختبار** — ثم ينشر النسخة المستقلة ويجهّز الحزمة:

```
.\scripts\release.ps1 -Zip
```

## الاختبارات والجودة

- حزمة اختبارات (xunit) في `tests/Daftari.Tests` تغطي منطق القبو: النقل وسلة المحذوفات وتعارض الأسماء، وترجيح البحث والبحث بعدة كلمات، والروابط والإشارات غير المرتبطة، والاستبدال، وضمانات التشفير (كشف العبث، عدم تكرار الناتج، رفض كلمة المرور الخاطئة).
- **فحص آلي على GitHub Actions** مع كل دفعة: بناء، اختبارات، والتأكد من أن النسخة المستقلة ما زالت تُبنى.
- قاعدة المشروع: المنطق في `Vault.cs` و`NoteCrypto.cs` قابلاً للاختبار، والواجهة في `MainForm.cs` رقيقة. أي منطق جديد يأتي بفحوصه.
- قاعدة البيانات: كل عملية تحذف أو تكتب فوق شيء **تتحقق أولاً** (القفل يفكّ التشفير قبل حذف الأصل، والحفظ يفحص تعديلات القرص، والحذف إلى سلة قابلة للاسترجاع).

## ما ليس دفتري

حدود مقصودة تحمي بساطته ووضوحه لقارئ الشاشة: لا رسم بياني للروابط، ولا مرفقات وصور، ولا مزامنة سحابية خاصة (استعمل مجلداً داخل OneDrive أو Google Drive)، ولا محرر منسّق — النص Markdown خام يقرؤه أي برنامج.

## التقنية

C#‎ / Windows Forms على .NET 8 — عناصر ويندوز الأصلية التي يتعامل معها NVDA بلا وسيط، مع إعلانات صوتية عبر UI Automation Notifications، وتحويل Markdown بمكتبة [Markdig](https://github.com/xoofx/markdig).
